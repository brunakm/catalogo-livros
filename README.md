# Catálogo de Livros 📚

Aplicação web desenvolvida como projeto acadêmico com o objetivo de praticar o desenvolvimento de aplicações React utilizando TypeScript, consumo de APIs REST e operações CRUD.

## 📋 Sobre o Projeto

O Catálogo de Livros é uma aplicação que permite cadastrar, visualizar e excluir livros através de uma interface simples e responsiva.

O projeto foi desenvolvido com React e TypeScript, utilizando Axios para realizar as requisições à API REST. A aplicação também utiliza tipagem para garantir maior organização e segurança no desenvolvimento.

## 🚀 Tecnologias Utilizadas

* React
* TypeScript
* Axios
* Vite
* CSS
* API REST
* CrudCrud

## ✨ Funcionalidades

* Cadastro de livros
* Cadastro de título e autor
* Definição do status do livro
* Listagem dos livros cadastrados
* Exclusão de livros
* Atualização automática da lista após alterações
* Consumo de API REST
* Tratamento de erros nas requisições
* Interface responsiva

## ▶️ Como Executar

1. Clone o repositório:

```bash
git clone https://github.com/brunakm/catalogo-livros.git
```

2. Acesse a pasta do projeto:
```bash
cd catalogo-livros
```

3. Instale as dependências:

```bash
npm install
```

4. Execute a aplicação:

```bash
npm run dev
```

5. Abra o endereço disponibilizado pelo Vite no navegador.

## 🛠️ Build do Projeto
Para gerar a versão de produção:
```
npm run build
```
